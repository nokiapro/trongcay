🧹 Xóa cache PWA

Dùng khi deploy bản mới nhưng app vẫn hiện version cũ (badge / SW cache). Trang này sẽ Unregister Service Worker, xóa Cache Storage, rồi chuyển về game.

Sẵn sàng. Bấm nút xanh để chạy.

Sau khi xong, nếu vẫn cũ: Chrome → F12 → Application → Storage → Clear site data, rồi mở lại index.html (hoặc /).
